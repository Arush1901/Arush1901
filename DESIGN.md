# Folio / Arush Maurya

The selected Folio concept, adapted for GitHub profile READMEs. A serif wordmark and five section dividers provide the visual identity; the compact introduction, project summaries, toolkit, activity, and contact links remain native Markdown or simple GitHub-supported HTML.

## Design

- Transparent, local SVG artwork that blends into GitHub's light and dark backgrounds.
- Georgia-style serif wordmark and section titles, with a restrained terracotta accent.
- Native project descriptions, accessible image alternatives, simple tables, and ordinary links.
- Vertically stacked projects to keep descriptions readable on narrow screens.
- No scripts, external font requests, or third-party image generators are required to display the profile.
- Short introduction, one-line project summaries, and a compact grouped toolkit replace the previous résumé-style descriptions.

## Motion

Locally hosted SVG animations add motion without changing the Folio identity:

- The wordmark's small terracotta ink mark travels slowly along the existing hairline on a 16-second loop. The name remains still.
- A serif tagline gently crossfades between three short lines on an 18-second loop. Desktop and mobile variants keep the lettering readable.
- A framed landscape gradually draws in charcoal with a restrained terracotta seam. It holds, then fades on a 22-second loop. The artwork has no signature, year, or edition label.

The SVGs use their own CSS; no README-level CSS or JavaScript is needed. Both stop animating when `prefers-reduced-motion: reduce` is active, showing a static accent and the first caption. If animation styling is unavailable, those same defaults remain readable.

The landscape also honors reduced motion by selecting a separate, complete still image through the README's picture sources. Its eight animated/still, light/dark, desktop/mobile assets are generated by `python3 scripts/living_edition.py` from `data/contributions.json`. Each calendar week supplies a strand; weekly contribution intensity changes ink and contour depth, and day-level intensity adds small local impressions. The underlying folded surface and terracotta seam are art direction rather than a quantitative chart. Mobile uses fewer visible strands for clarity.

The GitHub Actions workflow refreshes the public year-to-date contribution calendar daily at 02:23 UTC, on manual dispatch, and when its generator changes. No additional account secret is required. It rejects incomplete calendar responses before writing assets, preserving the last successful print if GitHub's markup changes or a request fails. The dated repository/follower snapshot above remains a separate static graphic.
