# Folio / Arush Maurya

The selected Folio concept, adapted for GitHub profile READMEs. A serif wordmark and six section dividers provide the visual identity; all detailed content remains native Markdown or simple GitHub-supported HTML.

## Design

- Transparent, local SVG artwork that blends into GitHub's light and dark backgrounds.
- Georgia-style serif wordmark and section titles, with a restrained terracotta accent.
- Native project descriptions, accessible image alternatives, simple tables, and ordinary links.
- Vertically stacked projects to keep descriptions readable on narrow screens.
- No scripts, external font requests, third-party image generators, or animated decorations are required to display the profile.

## GitHub snapshot

The activity graphic is a dated public snapshot: 20 public repositories, 3 followers, and 3 following as shown on the public profile on 19 October 2026. It is explicitly labeled as static. It does not imply live updates or include an invented contribution calendar.

To update it, change the counts and date in `assets/activity-light.svg`, `assets/activity-dark.svg`, and the README image alternative and date caption. To make it live later, add a separately reviewed data-generation workflow.
