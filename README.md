### a. Eclipse Fantasy

<sub>PREMIUM WALLPAPER PLATFORM · 2026–PRESENT</sub>

A live platform for premium 4K wallpapers, with globally distributed delivery through **Cloudflare Workers and R2**. I built a Sharp image pipeline for optimized renditions and EXIF/XMP ownership watermarking, alongside static generation, structured data, and automated sitemaps.

**1,000+ pages indexed** on Google Search Console.

<sub>Next.js · React · Node.js · Express.js · Cloudflare R2 / Workers · Sharp</sub>

[Visit the website ↗](https://eclipsefantasy.art)

---

### b. AI Commerce Gateway

<sub>AGENTIC COMMERCE · 2026–PRESENT</sub>

A goal-first pipeline that turns a natural-language shopping request and budget into a purchase flow. Buyer and merchant agents negotiate within policy limits, while a signed spend mandate and audit trail keep decisions bounded and explainable.

Built for the **Razorpay AI Buildathon**. The flow returns ranked cart options, asks for human approval when a selected option exceeds the budget, and creates a payment only after confirmation.

<sub>Node.js · Express.js · React · Groq LLM · Razorpay</sub>

[Explore the code ↗](https://github.com/Arush1901/AI-Commerce-Gateway)

---

### c. Smart AutoFill

<sub>CHROME EXTENSION · 2025</sub>

A Manifest V3 extension for filling forms across websites. A tabbed popup organizes Personal, Banking, and Work profiles, with content scripts, a background service worker, and one-click data clearing.

<sub>JavaScript · HTML · CSS · Chrome APIs</sub>
